GWAS Power Calculator

Adjust the sliders to see how sample size, effect size, allele frequency and case fraction affect statistical power at the genome-wide significance threshold (α = 5×10⁻⁸).

Parameters

For quantitative traits: OR = exp(β), so β = ln(OR). Set case fraction = 50%.
Proportion of study participants who are cases. Max 50% — having more cases than controls is always less efficient.

Binary trait (case-control) Purcell, Cherny & Sham, Bioinformatics, 2003

λ = β² × 2p(1−p) × N_eff
N_eff = 4N × π(1−π) [π = case fraction]
β = ln(OR), p = MAF
Power = Φ(√λ − 5.45) [α = 5×10⁻⁸]
N_eff < N when cases/controls are unbalanced. e.g. 10% cases → N_eff = 0.36 × N.

Quantitative trait (population-based) Purcell, Cherny & Sham, Bioinformatics, 2003

λ = β² × 2p(1−p) × N
β = effect in SD units per allele = ln(OR)
p = MAF, σ² = 1 (standardised trait)
Power = Φ(√λ − 5.45) [α = 5×10⁻⁸]
Set case fraction = 50% → N_eff = 4N×0.25 = N. This recovers the QT formula exactly.
