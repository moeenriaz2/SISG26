Background: Why Gene-Based Tests for Rare Variants?

Common variants (MAF > 1%) are well-powered in consortia with N > 100,000. Rare coding variants (MAF < 1%) present a fundamentally different problem: each individual variant is too rare for single-variant tests to be adequately powered, even at biobank scale.

The solution: aggregate rare variants within a gene into a single test statistic. If multiple rare variants in the same gene have effects in the same direction (loss-of-function, damaging missense), their combined signal can reach statistical significance.

The three core gene-based tests

TestWhat it detectsFormulaBest for
BurdenUnidirectional effects (all variants increase or all decrease risk)T = (Σ w_j S_j)² / VarLoF-only masks; strong prior for direction
SKATMixed-direction effects; variance component testQ = S′KS; p via DaviesMissense variants with uncertain direction
SKAT-OOptimal combination of Burden and SKATT(ρ) = ρ·Burden + (1−ρ)·SKATDefault — no prior on direction needed
ACAT-OCauchy combination of p-values across masksT = Σ tan((0.5−p_k)π)Multiple masks; robust omnibus test

References: Lee et al., Biostatistics, 2012 [SKAT-O] · Liu et al., Am J Hum Genet, 2019 [ACAT]

Why meta-analysis is essential for rare variants

Consider a gene with 12 rare pLoF variants (MAF < 0.1% each). The cumulative MAF across all 12 variants is ~1.2%. To detect an OR of 2.0 for the burden of LoF variants using SKAT-O at p < 2.5×10⁻⁶ (ExWAS threshold):

N cases (50% fraction)Power (SKAT-O, OR=2)Verdict
5,000~8%Essentially undiscoverable
50,000~61%Underpowered for most genes
200,000~97%Well powered — requires biobank meta-analysis

[Simulated power estimates for teaching. Real values depend on variant-level MAF distribution, effect sizes, and mask composition.]

Key published example: GPR75 rare loss-of-function variant (MAF < 0.01%) associated with 5.3 kg lower BMI was identified in N=640,000 across multiple biobanks. Invisible below N=200,000. (Akbari et al., Science, 2021)

The REMETA Framework

REMETA (Mbatchou et al., bioRxiv, 2024) extends REGENIE to multi-cohort gene-based ExWAS meta-analysis. Its key innovation: instead of sharing a per-phenotype covariance matrix (gigabytes of data per trait), each site shares a single sparse LD reference file that is reused across all phenotypes.

1
REGENIE Step 1 (per site) Whole-genome regression to account for relatedness and population stratification. Run once per cohort. Output: leave-one-chromosome-out (LOCO) predictions.
2
REGENIE Step 2 (per site) Exome association testing. Output: per-variant score statistics + sparse LD reference (stored once per site, reused for all phenotypes). SPA correction applied for binary traits with case-control imbalance.
3
REMETA (meta-analyst) Receives summary statistics + LD references from all sites. Reconstructs the covariance matrix Σ = Cov(S) per gene on the fly. Runs Burden, SKAT, SKAT-O, ACAT-O across all gene-mask combinations. 
# Illustrative REGENIE Step 2 command (per cohort)
# Reference: Mbatchou et al., Nat Genet, 2021
regenie \
  --step 2 \
  --bgen cohort1_exome.bgen \
  --sample cohort1_exome.sample \
  --phenoFile cohort1_phenotypes.txt \
  --covarFile cohort1_covariates.txt \
  --bt --spa \
  --pred cohort1_step1_pred.list \
  --anno-file gene_annotations_GRCh38.txt \
  --set-list gene_set_list.txt \
  --mask-def mask_definitions.txt \
  --aaf-bins 0.001,0.01 \
  --write-mask-snplist \
  --out cohort1_step2

# REMETA meta-analysis command
# Reference: Mbatchou et al., bioRxiv, 2024
remeta \
  --gene-based \
  --cohort cohort1_step2_T2D.regenie --ld-ref cohort1_step2.ld_ref \
  --cohort cohort2_step2_T2D.regenie --ld-ref cohort2_step2.ld_ref \
  --pheno T2D \
  --tests burden,skat,skato,acato \
  --mask pLoF,pLoF_missense5 \
  --af-range 0 0.01 \
  --min-mac 5 --spa \
  --out T2D_ExWAS_meta

Part 2: Applying the Significance Threshold and Basic QC

# ExWAS significance threshold
threshold <- 2.5e-6   # p < 2.5e-6 for ~20,000 genes, alpha=0.05

# Apply threshold
sig <- remeta_out[P_META < threshold]
cat("Genes passing ExWAS threshold:", nrow(sig), "\n")
print(sig[order(P_META), .(GENE, N_VARIANTS, MAC, BETA_burden, SE_burden, P_META, P_HET)])

# Compute 95% confidence intervals for significant genes
sig[, CI_lo := round(BETA_burden - 1.96 * SE_burden, 3)]
sig[, CI_hi := round(BETA_burden + 1.96 * SE_burden, 3)]
cat("\n95% CIs for significant genes:\n")
print(sig[order(P_META), .(GENE, BETA_burden, CI_lo, CI_hi, P_META)])

# MAC quality control filter
cat("\nGenes with MAC < 10 (unreliable, should be excluded):", 
    sum(remeta_out$MAC < 10), "\n")
cat("Genes retained after MAC >= 10:", sum(remeta_out$MAC >= 10), "\n")

# Heterogeneity check
het_flag <- remeta_out[P_HET < 0.05]
cat("\nGenes with significant heterogeneity (P_HET < 0.05):", nrow(het_flag), "\n")

Summary: Key Concepts

  • Gene-based tests aggregate rare variant signals across a gene. The choice of test (Burden vs SKAT-O) reflects a biological prior about effect direction.
  • Masks define which variant classes are aggregated. pLoF is most interpretable; broader masks (pLoF + missense) increase power at the cost of interpretability.
  • MAC filter: always require MAC ≥ 10 (or higher) for gene-based tests. Below this, test statistics are unreliable regardless of p-value.
  • ExWAS threshold p < 2.5×10⁻⁶ corresponds to ~20,000 genes. Some groups use the stricter p < 6.7×10⁻⁷ when testing multiple masks × tests.
  • Heterogeneity with K=2 is very low-powered. P_HET > 0.05 does not mean the two cohorts agree — it means you cannot detect disagreement with only 2 cohorts.
  • REMETA's key innovation: one sparse LD reference per study, not per phenotype. This enables PheWAS at biobank scale without gigabyte file sharing per trait.
