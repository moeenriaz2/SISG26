Background: Why Meta-Analysis?

Genome-wide association studies (GWAS) aim to identify genetic variants associated with complex traits. A fundamental challenge is that most common variants have very small effects (OR typically 1.03–1.15). The statistical power to detect such effects at the genome-wide significance threshold (p < 5×10−8) requires enormous sample sizes.

Consider a variant with OR = 1.12, MAF = 0.20, in a balanced case-control study. Under the GWAS significance threshold:

N (total)PowerVerdict
5,000~3%Virtually blind — any hit is almost certainly a false positive
50,000~52%Underpowered — misses half of real associations
300,000~99%Well powered — meta-analysis achieves this

Power formula: λ = β² × 2p(1−p) × N_eff, where N_eff = 4N × π(1−π). Power = Φ(√λ − zα/2), zα/2 = 5.45 for α = 5×10−8.

The METAL approach

METAL (Willer, Li, Abecasis, Bioinformatics 2010) performs fixed-effects meta-analysis using inverse-variance weighting. Each study contributes a per-variant effect estimate (β̂) and standard error (SE). The pooled estimate is:

wᵢ = 1 / SEᵢ²                        # weight for study i
β_meta = Σ(wᵢ × β̂ᵢ) / Σwᵢ            # pooled effect
SE_meta = 1 / √(Σwᵢ)                  # pooled SE
Z_meta  = β_meta / SE_meta             # Z-score
p-value = 2 × Φ(−|Z_meta|)            # two-sided p

# Heterogeneity
Q  = Σ wᵢ × (β̂ᵢ − β_meta)²           # Cochran's Q, df = K−1
I² = max(0, (Q − (K−1)) / Q) × 100%   # between-study variance fraction

Studies with larger sample sizes (smaller SEs) receive more weight. Importantly, only summary statistics (β̂, SE, N) need to be shared — no individual-level data is required.

Part 1: Exploring the Cohort Summary Statistics

METAL is flexible. It can run:
  • By default, METAL combines p-values across studies using sample size and direction of effect
  • Alternatively, standard error-based weights (requires that BETA and SE use the same units across all studies — e.g. all on the same trait scale)
It requires a driver file, which:
  • Describes the input files (column names, separators, file paths)
  • Defines the meta-analysis strategy (scheme, marker column, effect/SE columns)

Part 2: Manual Fixed-Effects Meta-Analysis in R

Before using METAL software, we implement the meta-analysis from scratch to understand exactly what METAL is computing.

# Sort all cohorts by SNPID to ensure alignment
c1 <- c1[order(SNPID)]
c2 <- c2[order(SNPID)]
c3 <- c3[order(SNPID)]

# Step 1: Calculate inverse-variance weights
w1 <- 1 / c1$SE^2
w2 <- 1 / c2$SE^2
w3 <- 1 / c3$SE^2
w_sum <- w1 + w2 + w3

# Step 2: Pooled effect estimate and SE
beta_meta <- (w1 * c1$BETA + w2 * c2$BETA + w3 * c3$BETA) / w_sum
se_meta   <- 1 / sqrt(w_sum)

# Step 3: Z-score and p-value
z_meta <- beta_meta / se_meta
p_meta <- 2 * pnorm(-abs(z_meta))

# Step 4: Heterogeneity statistics
Q  <- w1*(c1$BETA - beta_meta)^2 + w2*(c2$BETA - beta_meta)^2 + w3*(c3$BETA - beta_meta)^2
I2 <- pmax(0, (Q - 2) / Q) * 100   # df = K-1 = 3-1 = 2
p_het <- pchisq(Q, df = 2, lower.tail = FALSE)

# Compile results
results <- data.frame(
  SNPID     = c1$SNPID,
  A1        = c1$A1,
  BETA_meta = round(beta_meta, 4),
  SE_meta   = round(se_meta,   4),
  Z_meta    = round(z_meta,    3),
  P_meta    = signif(p_meta,   3),
  I2        = round(I2,        1),
  P_het     = round(p_het,     4),
  N_total   = c1$N + c2$N + c3$N
)

print(results)

Part 5: Quality Control for Meta-Analysis

Before contributing to a meta-analysis, each cohort should pass QC. The most common failure modes are:

  1. Strand flips: Array A reports C/G, Array B reports G/C. Effect direction is inverted.
  2. Palindromic SNPs (A/T or C/G at MAF ≈ 0.5): Cannot resolve strand without allele frequency information.
  3. Genomic control inflation (λ): λ = median(χ²) / 0.456. Values > 1.1 indicate uncorrected stratification.
  4. Imputation quality: Variants with INFO < 0.3 should be excluded before contributing.
# Compute genomic control λ for cohort 1
chi2_vals <- (c1$BETA / c1$SE)^2    # chi-squared = Z²
lambda_gc <- median(chi2_vals) / qchisq(0.5, df = 1)
cat("Genomic control lambda (cohort 1):", round(lambda_gc, 3), "\n")

# Check for any extreme chi-squared values (potential errors)
summary(chi2_vals)
which(chi2_vals > 100)   # flag extreme outliers

Summary: Key Concepts

  • Inverse-variance weighting gives more weight to larger, more precise studies. A study with SE=0.02 gets weight 2,500; a study with SE=0.06 gets weight 278 — a 9× difference.
  • Cochran's Q and I² measure between-study heterogeneity. With K=3 studies, Q has only 2 degrees of freedom — the test is low-powered and I² should be interpreted cautiously.
  • Meta-analysis ≈ mega-analysis in efficiency: sharing β̂ and SE is asymptotically equivalent to sharing individual genotypes (Lin & Zeng, Biometrics, 2010).
  • Winner's curse: single-cohort effect sizes are inflated by 10–30%. Always use the meta-analysis estimate for clinical or pharmacological applications.
